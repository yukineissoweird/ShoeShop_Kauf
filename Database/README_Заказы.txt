Реализация модуля заказов

Важные особенности исходной схемы базы данных:
1. Order_List.Id_Order является одновременно первичным ключом и внешним ключом на Product.Id.
   Поэтому в текущей схеме один товар может быть связан максимум с одним заказом.
2. В таблицах Order_Items и Order_List первичные ключи не имеют IDENTITY.
   Для новой позиции заказа ID_Order_list назначается приложением как MAX(Id_Order_list) + 1.
3. Для заполнения формы необходимы записи в Product, Order_Status и Pickup_Point.
4. SQL-скрипт Labascript.sql содержит структуру таблиц, но не содержит справочных или тестовых данных.

Модуль не меняет исходную структуру базы данных.
